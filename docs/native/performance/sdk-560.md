# SDK-560: one integrity hash per static query

Measured on 2026-09-21 against the same M45-observe installation and Apple M4 as
[SDK-559](../performance.md). The worktree includes SDK-559's dev-profile dependency
overrides. The release profile is unaffected by those overrides.

## Change

`Installation::open` computes the full-file SHA-256 once and supplies that identity to
binary identification. Each public static query reads and hashes the executable once. A
cache miss uses those verified bytes for candidate discovery, and `registry_fields` uses
the same bytes for its field input. The full-file hash covers the ARM64 slice selected
and hashed at open, so a second slice hash is unnecessary on a later read.

The existing path-retarget, missing-file, unreadable-file, and changed-byte checks remain
at the read boundary. `BoundAnalysis` retains the first integrity failure permanently.
No metadata shortcut or persistent cache was added.

## Release measurements

The [measurement driver](../../../tools/profiling/measure.py) built first, then ran
each executable twice. Runs were sequential under ordinary filesystem-cache conditions.
The first after-change run includes host variation; compare the repeated run for the
ticket's warmed baseline. All commands exited zero.

| Workload | Before | After |
| --- | ---: | ---: |
| `registries` first | 3.57 s | 1.78 s |
| `registries` second | 2.97 s | 1.77 s |
| Loader parity first | 3.85 s | 2.82 s |
| Loader parity second | 3.67 s | 2.66 s |

The warmed registry query fell 40.4%. The example's JSON before and after is byte-for-byte
equal. Raw timings and outputs are in `.local/sdk-560-baseline/` and
`.local/sdk-560-after/`.

The temporary source-copy instrumentation in `.local/sdk-560-instrumented-source/`
records 71 hash calls for the first registry answer: two full-file hashes, one slice
hash at open, and 68 small content-file hashes. A temporary same-object example made
three equal `registries()` calls. Its log records 73 hash calls total: one full-file
hash at open, one slice hash at open, 68 content hashes, and one full-file hash for
each of the three public queries. Candidate discovery ran once. Instrumentation logs
are in `.local/sdk-560-instrumented/` and `.local/sdk-560-cache-phases/`; their wall
times are not the uninstrumented benchmark.
