# Spikes and proposals

The documents here are experiments and the proposals that came from them. None of them is an
accepted design. The [specification](../specs/native.md), the [technical design](../design/architecture.md),
the [simplification decision](../design/simplification.md) and the [roadmap](../roadmap.md) stay the
authority. An accepted proposal moves to `docs/design/` and changes those documents.

Engine facts found by a spike go to the knowledge pages in `docs/native/`, indexed by the
[engine knowledge index](../engine-knowledge.md). Each spike's results and rule conclusions stay
with Atlas, in `docs/prototypes/`.
